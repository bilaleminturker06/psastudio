# PSA Studio

**PSA Studio** is a diagnostic, ECU flashing, and telecoding application for PSA / Stellantis group vehicles (Peugeot, Citroën, DS, Opel). It serves as a fast, user-friendly alternative to tools like Diagbox for ECU identification, telecoding, and calibration updates.

---

## Features

* **ECU Diagnostics & Identification:** Read ECU hardware/software information, DTCs, and parameters.
* **Telecoding & Configuration:** Modify vehicle settings, BSI zones, and ECU parameters.
* **ECU Flashing:** Write firmware manually and calibration files directly to modules.
* **Hardware Support:** Compatible with **VCI interfaces** and vlud **Arduino** setups.
